# College Pick'em

## Overview

College Pick'em is a free Progressive Web App (PWA) for a private college football pick'em league.

The goal is to replace our Google Sheets + Apps Script workflow with a modern mobile app while preserving all existing league rules.

### Launch Goal

Ready for Week 1 of the 2026 college football season.

---

# Version 1 Goals

- Login
- Weekly picks
- Hidden picks
- Standings
- Results
- Push notifications
- Admin tools
